# .github

`.github` and `.github-private` repositories are used internally by GitHub to set a pinned `README.md` to a GitHub organization page. The actual `README.md` that will be displayed should be located under `./profile`. `.github/profile/README.md` is displayed publicly while `.github-private/profile/README.md` is private to the organization members.

This is the public counterpart, visible only to everyone.
